套路手法识别

        
          
偷梁换柱表面 claude-sonnet，后台反代国产模型或降级 Haiku问版本号 + 长上下文推理题

          
假 Thinking模型不支持 thinking，前端伪造 <think> 标签看原始 JSON 有没有结构化 thinking 块与签名

          
缓存倍率暗扣官方命中缓存 1 折，私下调成 3 折或全价比对 cache_read_input_tokens 与扣费

          
token 虚报usage 报得比实际多 20–40%固定文本比对官方 tokenizer
