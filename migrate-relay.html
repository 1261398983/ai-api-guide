主站挂了不是最难受的 —— 最难受的是挂的时候账号里还有钱、任务正跑到一半。留一个备用站，改一行环境变量就能切。

一、切换只需要改什么

绝大多数工具只认两个东西：base_url 和 key。

Claude Code

export ANTHROPIC_BASE_URL="https://api.dshapi.icu"
export ANTHROPIC_AUTH_TOKEN="sk-你的key"
export ANTHROPIC_MODEL="claude-sonnet-4-5"

Codex CLI / OpenAI SDK 系

export OPENAI_BASE_URL="https://api.dshapi.icu/v1"
export OPENAI_API_KEY="sk-你的key"

Cherry Studio / LobeChat / NextChat / One API 系

字段填什么
API 地址 / Base URLhttps://api.dshapi.icu/v1
密钥sk- 开头的 key
模型名见下方清单

Cline / Roo Code / Continue 等 VS Code 插件

协议选 OpenAI Compatible，Base URL 填 https://api.dshapi.icu/v1，其余同上。

二、迁移检查清单

  • 新站的 /v1/models 能返回你需要的模型名
  • 同一个 prompt 连发两次，第二次更便宜（缓存生效）
  • usage 字段里有 prompt_cache_hit_tokens（计费透明）
  • 主站 key 先别删，跑一周双写对比再决定
  • 两家都只留一个月用量，不锁大额

三、模型名对照（常见）

glm-5.2                glm-5.3                glm-5.3-flash
kimi-k2.8              kimi-k3                minimax-m3

Claude / GPT 系模型走独立分组，模型名以 /v1/models 返回为准。

四、迁移前必须确认的三条计费差异

  1. 缓存读怎么计价 —— 正常 10% 左右，15%~30% 就要注意
  2. 输出按什么倍率 —— 有的站输入便宜输出贵，总价反而更高
  3. 有没有最低消费 / 套餐绑定 —— 按量的站更灵活

五、常见迁移问题

Q：换站之后 Claude Code 报模型不存在？

先 curl /v1/models 拿到确切模型名再填，别照抄教程。

Q：Codex CLI 提示 base_url 格式错误？

Codex CLI 要带 /v1，Claude Code 不要带 /v1。这是最高频的坑。

Q：两边的 key 能混用吗？

不能，key 是站点级别的。

Q：担心新站跑路？

1 元起充的站先充最低额度，跑两周再续。
