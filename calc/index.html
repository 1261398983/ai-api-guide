2. 任务分级能省多少

这个动作不需要换渠道，改的是调用习惯。它通常比"找更便宜的站"省得更多。

3. 为什么输出 token 这么贵

对比项典型情况
输出单价 / 输入单价3 – 5 倍

在提示词里加一句「用最少的话说明」或「控制在 200 字内」，通常能省 20–40%。

4. 上下文累积的隐形开销

多轮对话里，每一轮都要把前面全部历史重新送进去计费。跑 20 轮，第 20 轮的输入量约是第 1 轮的 20 倍。

轮次累计输入 token相对第 1 轮
做法：完成一个任务就开新会话。Claude Code 里是 /clear。这一条一个月能省 20–30%。
