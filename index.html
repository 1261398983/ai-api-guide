三分钟接入

# Windows PowerShell
$env:ANTHROPIC_BASE_URL="https://your-endpoint.example.com"
$env:ANTHROPIC_AUTH_TOKEN="你的Key"
claude

# macOS / Linux
export ANTHROPIC_BASE_URL="https://your-endpoint.example.com"
export ANTHROPIC_AUTH_TOKEN="你的Key"
claude
# 环境变量方式
export OPENAI_BASE_URL="https://your-endpoint.example.com/v1"
export OPENAI_API_KEY="你的Key"
codex

# 或写入 ~/.codex/config.toml
model_provider = "relayx"

[model_providers.relayx]
name = "示例网关"
base_url = "https://your-endpoint.example.com/v1"
env_key = "OPENAI_API_KEY"
设置 → 模型服务 → 添加提供商
  类型      : OpenAI（或 Anthropic）
  API 地址  : https://your-endpoint.example.com/v1
  密钥      : 你的Key
  → 点击"检查"，自动拉取可用模型列表
from openai import OpenAI

client = OpenAI(api_key="你的Key", base_url="https://your-endpoint.example.com/v1")
resp = client.chat.completions.create(
    model="claude-sonnet-4-5",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "你的Key",
  baseURL: "https://your-endpoint.example.com/v1",
});
curl https://your-endpoint.example.com/v1/chat/completions ^
  -H "Authorization: Bearer 你的Key" ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"claude-sonnet-4-5\",\"messages\":[{\"role\":\"user\",\"content\":\"hi\"}]}"
统一端点：https://your-endpoint.example.com/v1 —— 所有兼容 OpenAI SDK 的项目直接替换 base_url 即可迁移。

中转站怎么选？6 条判断标准 + 5 个 60 秒验证动作不怕贵，怕不透明。含可直接复制的 curl 验证命令与账单拆解。
